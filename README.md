# GDG on Campus — Sarala Birla University

The official website for GDG on Campus at Sarala Birla University, Ranchi.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Experience & motion principles
- Editorial, warm minimal design inspired by DevFest Ranchi.
- Intro and reveal transitions are deliberately subtle, with skip and reduced-motion support.
- The custom elephant intro and photo reveal are reserved for the next asset integration step.
- Real event imagery, official logos, organizer details, and social links should replace clearly marked placeholders only after approval.

## Content integrity
DevSpark 2026 is currently the only completed SBU GDG event featured on this first pass. Technology domains are areas of interest, not claims of events already conducted.
